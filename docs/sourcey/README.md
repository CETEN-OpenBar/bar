# Sourcey generated OpenAPI docs

This directory contains a static Sourcey build for `bar.openapi.yml`.

Generated with:

```sh
sourcey build ./bar.openapi.yml -o ./docs/sourcey --quiet
```

The generated documentation entrypoint is `index.html`; the operation reference
is available in `api.html`. Sourcey also emits `search-index.json`, `llms.txt`,
and `llms-full.txt` for local search and LLM-readable API reference workflows.

The generated API reference currently covers 72 OpenAPI path items and 103
operations from the repository's checked-in `bar.openapi.yml` specification.
